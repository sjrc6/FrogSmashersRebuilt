DISMISS_NOTICE = false;

To hide the in-game notice, change the setting above to true and restart the game.
The file stays in docs unless a possible issue is detected and the notice is enabled.

If you see "potential IPv6 Firewall issues detected, see IPv6-issues.txt" the game detected
a possible windows firewall problem affecting IPv6 router or neighbor discovery.
It checks for missing ICMPv6 allowances (types 134, 135, 136).

These rules should be enabled by default but they might be disabled on your machine
due to a Windows update that broke them.

This can sometimes cause issues when steam tries to create a direct IPv6 connection shortly
after you join a lobby. If you do get these issues you can either try to fix the firewall rules
or have the lobby host switch the Steam API to "LEGACY" in the advanced lobby settings.

Repair missing or disabled default IPv6 rules instructions:

1. Close the game.
2. Open Start, search for "Windows PowerShell", and choose "Run as administrator".
3. Copy this entire block into PowerShell and press Enter:

& {
    $ErrorActionPreference = 'Stop'
    $fsrStamp = Get-Date -Format 'yyyyMMdd-HHmmss'
    $fsrBackup = Join-Path ([Environment]::GetFolderPath('Desktop')) "FSR-firewall-$fsrStamp.wfw"
    netsh advfirewall export "$fsrBackup"
    if ($LASTEXITCODE -ne 0) { throw 'Firewall backup failed; no rules changed.' }

    $fsrNames = @(
        'CoreNet-ICMP6-RA-In'
        'CoreNet-ICMP6-NDS-In'
        'CoreNet-ICMP6-NDA-In'
    )
    $fsrDefaults = @(Get-NetFirewallRule -PolicyStore SystemDefaults -Name $fsrNames)
    $fsrExisting = @(Get-NetFirewallRule -PolicyStore PersistentStore)
    foreach ($fsrRule in $fsrDefaults) {
        if ($fsrRule.Name -notin $fsrExisting.Name) {
            $fsrRule | Copy-NetFirewallRule -NewPolicyStore PersistentStore
        } else {
            Set-NetFirewallRule -PolicyStore PersistentStore -Name $fsrRule.Name -Enabled True -Action Allow -Profile Any
        }
    }
    Get-NetFirewallRule -PolicyStore ActiveStore -Name $fsrNames |
        Format-Table Name, Enabled, Action, Profile
    Write-Host "Firewall backup: $fsrBackup"
}

4. The three rows should show Enabled=True, Action=Allow, Profile=Any.

The .wfw backup contains the previous firewall policy.
You can need restore that policy using Windows Defender Firewall with
Advanced Security > Action > Import Policy.
